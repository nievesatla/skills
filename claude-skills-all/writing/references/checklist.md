# Checklist

Two parts. The attack list drives the red-pen loop (name the exact sentence that fails, not a vague verdict). The final pass runs once, silently, before anything is returned.

## Attack list (each red-pen round)

1. **Workslop test.** Would the reader need to ask a follow-up before they could act? If yes, it fails. Everything below is how it fails.
2. **Missing decisions.** Dates, owners, numbers, next steps, a clear stance. "We should consider" and "we'll revisit" are not decisions.
3. **Empty calories.** Sentences that add no information. Mark each for deletion.
4. **Unverifiable claims.** Any fact or number not supported by what the user gave you. Cut it or mark `[VERIFY]`. Never invent a number to make a sentence land.
5. **Only-you line.** At least one line only this user could have written: a real detail, example, or named trade-off. Run the portability test on every generic sentence.
6. **Patterns.** Anything from `patterns.md`, strongest first: reframes, closers, staging, dashes, triads, bold labels.
7. **Voice.** If a profile exists: sentence lengths in range, no never-list words, signature moves at their natural rate rather than caricature rate. Would a colleague who reads the user's writing weekly pause on any sentence?
8. **Fact diff.** Compare against the source. Did the rewrite add or drop any fact, name, number, date, quote, citation, ranking, or commitment? An unsupported addition is an error. A lost claim is an error unless a pattern called for cutting it.

Fix every flag, not most. Repeat until a full pass finds nothing. If a result still feels flat, the attack pass went easy: run two more rounds, harder on the workslop test.

## Final pass

1. Cut the first sentence if it's throat-clearing.
2. Replace vague claims with specific ones, or ask for the detail.
3. Remove fake importance.
4. Search for negative parallelism, including across sentence boundaries and in headings.
5. Search for the tells that survive rewrites most often: a reframe, a one-line closer, a dash, a triad, a bold label.
6. Remove unearned analogies and metaphor verbs.
7. Replace bloated verbs with plain ones; repeat the right word instead of cycling synonyms.
8. Remove chat residue and meta commentary.
9. Break up repeated sentence shapes and uniform paragraph lengths.
10. Cut the ending if it only repeats the point.
11. Read it aloud. Does it sound like a person, or like an AI trying hard to imitate one? If forced, simplify.
12. Would the writer recognize it as their own voice?
13. Does the output match the mode's return format (see SKILL.md)?

For audits: every finding names the pattern, quotes the line, and gives a short fix. No rewrite, no score, no claim about AI authorship.
